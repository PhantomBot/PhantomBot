Package com.mcawful

Class PanelSessionManager

java.lang.Object
com.mcawful.PanelSessionManager
public final class PanelSessionManager extends Object
Panel login sessions that are started by signing in with a passkey.

The browser holds a random session ID in a cookie. Only the SHA-256 of the ID is kept here, and only in memory, so every session ends when the bot restarts.
