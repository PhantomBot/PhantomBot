Package com.mcawful

Class PasskeyVerifier

java.lang.Object
com.mcawful.PasskeyVerifier
public final class PasskeyVerifier extends Object
Server-side checks for passkey (WebAuthn) registration and sign-in on the panel.

Attestation is not requested, so the browser hands over the public key in SubjectPublicKeyInfo form and no CBOR parsing is needed. Only ES256 (P-256) and RS256 keys are accepted.

This class holds no bot state. Every verify method throws IllegalArgumentException with the reason when a check fails.
