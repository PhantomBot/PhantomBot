Interface SocialPlatform

All Known Implementing Classes:
BlueskyPlatform
public interface SocialPlatform
A social media platform the bot can post to and read activity from

A platform is registered in SocialPlatformRegistry. SocialPoller calls fetch(SocialPollType, String) for each of its poll types and fires the social events, and ./core/social.js provides the chat command, automatic posts and repost rewards for every platform. The settings of a platform are kept in the database table named after its id.

Methods that send requests block, so scripts should call them from a timer rather than from an event hook
